# Альбом.com — запуск, публикация и безопасность

## Что умеет сайт

- отдельные аккаунты по email и паролю;
- ссылка для сброса пароля через стандартное письмо Supabase;
- альбомы с индивидуальным паролем и бессрочной ссылкой;
- доступ к чужому альбому только после ссылки, пароля и входа в аккаунт;
- папки с любым названием и любым цветом из палитры;
- загрузка фото/видео напрямую в альбом или в папку — до **35 файлов за раз**;
- загрузка аватара, настройка имени, мобильная версия;
- хранение файлов в приватном Supabase Storage.

## 1. Один раз установите Node.js

1. Откройте https://nodejs.org.
2. Нажмите большую кнопку **LTS** и установите программу.
3. Перезапустите VS Code.

## 2. Создайте проект Supabase

1. Откройте https://supabase.com/dashboard.
2. Нажмите **New project** и дождитесь статуса **Active**.
3. Откройте **Project Settings** (шестерёнка) → **API**.
4. Скопируйте:
   - **Project URL**: `https://xxxx.supabase.co`;
   - **Publishable key** или **anon key**.

Никогда не используйте `service_role key` в сайте: он даёт полный доступ к данным.

## 3. Подключите Supabase к сайту

1. В VS Code откройте `.env`.
2. Вставьте свои данные:

```env
VITE_SUPABASE_URL=https://xxxx.supabase.co
VITE_SUPABASE_ANON_KEY=ваш_publishable_или_anon_ключ
VITE_APP_URL=http://localhost:5173
```

3. Сохраните файл (`Cmd + S`).

## 4. Создайте базу и закрытое хранилище файлов

1. В Supabase откройте **SQL Editor** → **New query**.
2. В VS Code откройте `supabase/schema.sql`.
3. Скопируйте **весь текст файла**, вставьте в Supabase и нажмите **Run**.
4. Должно появиться зелёное сообщение `Success`.

> Этот файл рассчитан на чистую установку: он удалит альбомы и тестовые данные старой версии. Не запускайте его повторно после начала настоящего использования.

## 5. Почему возникает `email rate limit exceeded`

Это не ошибка вашего сайта. Бесплатный тестовый почтовый сервис Supabase ограничивает число писем, чтобы им не рассылали спам. Его нельзя и не нужно обходить кодом.

### Для теста

Подождите несколько минут и повторите попытку. Не нажимайте регистрацию/сброс много раз подряд.

### Для настоящего сайта: подключите SMTP

1. Создайте аккаунт у почтового провайдера: Resend, Brevo, Postmark или Mailgun.
2. Подтвердите ваш домен у провайдера. Это важно, иначе письма часто попадут в спам.
3. В Supabase откройте **Authentication** → **SMTP Settings**.
4. Включите **Enable custom SMTP**.
5. Скопируйте из почтового провайдера SMTP Host, Port, Username, Password и Sender email.
6. Вставьте данные и нажмите **Save**.

После SMTP регистрация и сброс пароля будут отправлять письма вашим пользователям без тестового лимита Supabase, но с лимитами выбранного почтового сервиса.

## 6. Настройте ссылки сброса пароля

В Supabase откройте **Authentication** → **URL Configuration**.

В **Redirect URLs** добавьте:

```text
http://localhost:5173/reset-password
```

Если сайт запустился на другом порту, например `5174`, добавьте ещё:

```text
http://localhost:5174/reset-password
```

Стандартный шаблон письма Supabase уже содержит ссылку для сброса. Изменять его не нужно.

## 7. Запустите сайт на компьютере

Откройте в VS Code **Terminal** → **New Terminal** и выполните:

```bash
npm install
npm run dev
```

Откройте адрес рядом со словом `Local`, например:

```text
http://localhost:5173/
```

Если меняли `.env`, остановите сервер `Ctrl + C` и вновь выполните `npm run dev`.

## 8. Как открыть на телефоне в одной Wi-Fi сети

1. Телефон и компьютер должны быть подключены к одному Wi-Fi.
2. После `npm run dev` найдите в терминале строку **Network**, например:

```text
Network: http://192.168.1.25:5173/
```

3. Откройте этот адрес на телефоне.
4. В `.env` укажите тот же адрес без слеша:

```env
VITE_APP_URL=http://192.168.1.25:5173
```

5. Перезапустите `npm run dev`.

`localhost` работает только на вашем компьютере. Его нельзя открыть на телефоне или отправить другу.

## 9. Как опубликовать сайт в интернет через Vercel

Это бесплатный простой вариант для начала.

1. Создайте аккаунт на https://github.com.
2. Создайте там новый **private** репозиторий и загрузите в него файлы этого проекта. Файл `.env` не загружайте.
3. Откройте https://vercel.com и войдите через GitHub.
4. Нажмите **Add New** → **Project** и выберите репозиторий.
5. В разделе **Environment Variables** добавьте:

```text
VITE_SUPABASE_URL = ваш Project URL
VITE_SUPABASE_ANON_KEY = ваш Publishable/anon key
VITE_APP_URL = https://ваш-проект.vercel.app
```

6. Нажмите **Deploy**.
7. После публикации скопируйте адрес Vercel, например `https://family-album.vercel.app`.
8. В Supabase → **Authentication** → **URL Configuration** добавьте:

```text
https://family-album.vercel.app/reset-password
```

9. В Vercel измените `VITE_APP_URL` на настоящий адрес сайта и нажмите **Redeploy**.

Теперь ссылки на альбомы будут открываться на телефонах и у других людей через интернет.

## 10. Как сайт защищает данные пользователей

- Пароли аккаунтов хранит Supabase Auth, сайт их не видит.
- Пароли альбомов хранятся в базе только как bcrypt-хеши.
- Фотографии находятся в **приватном** хранилище, а не в открытом доступе.
- Политики RLS проверяют владельца и доступ конкретного пользователя: аккаунт не может увидеть чужие альбомы без ссылки, пароля и созданной записи доступа.
- Никогда не добавляйте `service_role key`, пароль от базы или ключ OpenRouter в React/Vite `.env` и не публикуйте их в GitHub.
- Регулярно обновляйте зависимости: `npm update`.

## OpenRouter

OpenRouter не требуется для базовой работы семейного альбома. Если позже появятся ИИ-подписи к фотографиям, храните `OPENROUTER_API_KEY` только в Secrets Supabase Edge Function, не в браузере.
